## 1. 设计原则

1. **三区布局**：顶部状态、中部记录、底部控制——视线动线自上而下「看状态 → 读译文 → 按按钮」；
2. **状态一眼可见**：指示灯 + 文案 + 电平条，任何时刻 1 秒内判断"它在干嘛"；
3. **单手可操作**：主按钮够大，核心操作（开始/停止、口音切换、静音）都在底部一行；
4. **暗色主题**：长时间盯屏舒适，状态色在暗底上区分度高。

## 2. 信息架构（页面清单）

| 错误提示条 | 主窗体顶部黄/红条 | 设备缺失、网络失败等 |

## 5. 状态与界面映射

### 5.1 状态流转线性图（核心）

```
(S0) 待机 ─点击开始→ (S1) 监听 ─VAD触发→ (S2) 采集中 ─静音≥750ms→ (S3) 识别中
  ▲                                                                          │
  │                                                                          ▼
  │                            (S5) 播报中 ◀─译文就绪─ (S4) 翻译中 ◀─中文文本─┘
  │                                │
  └────────── 点击停止（任意状态立即返回 S0）◄──播放完毕，回到 S1─────────────────┘
```

一句话走完 S1→S2→S3→S4→S5 后**自动回到 S1 继续监听**，形成循环，直到用户点击停止。

### 5.2 状态-界面对照表

| 状态 | 指示灯 | 状态栏文案 | 记录区表现 | 主按钮 |
|---|---|---|---|---|
| S0 待机 | ● 灰 `#8a8f98` | 待机 | 历史只读 | ● 开始录音（绿） |
| S1 监听 | ● 绿 `#22c55e` | 监听中… | 电平条活跃 | ■ 停止（红） |
| S2 采集中 | ● 绿，呼吸闪烁 | 正在听… | 电平条活跃 | ■ 停止 |
| S3 识别中 | ● 蓝 `#3b82f6` | 识别中… | (…) spinner | ■ 停止 |
| S4 翻译中 | ● 橙 `#f59e0b` | 翻译中… | zh 行已出，en 行 (…) | ■ 停止 |
| S5 播报中 | ● 紫 `#a855f7` | 播报中… | 卡片完整，[重播]变 [⏸ 停止] | ■ 停止 |

## 10. 快捷键

| 键 | 功能 |

## 11. 边界与异常的界面反馈

| 情形 | 界面表现 |
|---|---|
| 未检测到麦克风 | 错误红条 + 设备列表指引；开始按钮禁用 |
| 识别结果为空（噪声） | 不生成卡片，静默继续监听 |
| LLM 失败回退直译 | 黄条提示"翻译引擎回退：Whisper 直译" |
| TTS 网络失败 | 译文正常上屏，黄条"播报失败"；可点 [重播] 重试 |
| 模型缺失/损坏 | 弹出首次运行下载对话框 |
| 录音中拔出麦克风 | 红条提示 + 自动回到 S0 |
