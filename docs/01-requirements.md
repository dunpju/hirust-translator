## 1. 项目背景与目标

做一款 Windows 桌面应用：用户对着麦克风**说中文**，应用实时完成「语音识别 → 中译英 → 英文语音播报」全链路，如同一台随身同声传译机。

**核心目标**

1. 一键开始，说完一句话停顿后约 1~2 秒内听到英文播报；
2. 语音识别在本地完成，不上传音频；无任何 API Key 也能完整使用；
3. 口音可切换：**美式（默认）/ 英式**，切换同时影响朗读音色与译文用词/拼写；
4. 译文自动朗读，可静音；外放场景有回声防护。

**非目标（v0.1 不做）**：英→中反向翻译、多人会议分离说话人、移动端。

## 2. 用户与场景

| 场景 | 描述 | 关键诉求 |
|---|---|---|
| A. 英语学习跟读 | 学习者朗读/对话练习，想立刻听到地道英文表达 | 低延迟、口音标准可切换 |
| B. 线上会议辅助 | 中文参会者借助工具把话翻成英文播出/阅读 | 断句准确、连续工作稳定 |
| C. 出境旅行沟通 | 旅行者对 App 说中文，让对方听英文 | 操作极简、大按钮、可重播 |

## 3. 功能需求

优先级：P0 = v0.1 必须；P1 = v0.1 尽量；P2 = 后续版本。

| 编号 | 优先级 | 功能 | 说明 |
|---|---|---|---|
| FR-01 | P0 | 实时录音采集 | 默认输入设备，采集→单声道 16 kHz（whisper 要求），内置重采样 |
| FR-02 | P0 | 语音活动检测（VAD）与自动断句 | 能量阈值 + 静音时长（默认 750 ms）切分句子；启动时自动校准环境噪声 |
| FR-03 | P0 | 中文语音识别 | whisper.cpp 本地推理，语言=zh；模型 tiny/base/small 可选，默认 base |
| FR-04 | P0 | 中→英翻译 | 双引擎：① LLM API（OpenAI 兼容，推荐 DeepSeek，质量高）；② Whisper 内置直译（离线、零配置）。默认：配了 Key 用 LLM，否则/失败时自动回退直译 |
| FR-05 | P0 | 译文自动播报 | Edge-TTS 神经音色，自动朗读最新译文；可一键静音；播报按顺序串行 |
| FR-06 | P0 | 口音切换 | **默认美式**；美式/英式即时切换。影响：TTS 音色（en-US-Aria ↔ en-GB-Sonia）+ LLM 翻译提示词（美式/英式拼写与用词） |
| FR-07 | P0 | 开始/停止录音 | 主控按钮 + 快捷键 Space |
| FR-08 | P0 | 实时状态可视化 | 状态灯（待机/监听/识别/翻译/播报）、输入电平条、进行中指示 |
| FR-09 | P0 | 设置持久化 | config.toml，首启生成默认配置 |
| FR-10 | P1 | 历史记录 | 每句一张卡片：时间戳 + 原文 + 译文；支持重播/复制/导出 txt |
| FR-11 | P1 | 回声防护 | 扬声器模式：播报期间暂停拾音；耳机模式可关闭防护（ duplex） |
| FR-12 | P1 | 输入电平表 | 实时显示，辅助确认麦克风正常与灵敏度 |
| FR-13 | P1 | 模型管理 | 模型选择 + 应用内下载（hf-mirror 镜像优先，HF 兜底），断点显示进度 |
| FR-14 | P2 | 双向翻译 | 英→中（后续版本） |
| FR-15 | P2 | 悬浮字幕窗 / 全局热键 | 后续版本 |

## 4. 非功能需求

| 编号 | 维度 | 要求 |
|---|---|---|
| NFR-01 | 延迟 | 断句完成 → 译文上屏 ≤ 2 s（base 模型，4 核 CPU）；译文就绪 → 开始播报 ≤ 1.5 s |
| NFR-02 | 隐私 | 语音与识别全程本地；仅译文文本（可选）发送 LLM、译文文本发送 Edge-TTS 服务 |
| NFR-03 | 可用性 | 无 API Key、无外网（除 TTS）时功能可用（直译模式；TTS 失败仅显示文字并提示） |
| NFR-04 | 平台 | Windows 10/11 x64 优先；需要麦克风 + 扬声器或耳机 |
| NFR-05 | 资源 | 常驻内存 ≤ 1 GB（base 模型）；空闲 CPU ≤ 5% |
| NFR-06 | 稳定性 | 单句识别/翻译失败不中断会话，状态栏提示错误并继续监听 |
| NFR-07 | 界面语言 | 中文 |

## 5. 验收标准

1. Windows 11 + 默认麦克风环境，点击「开始录音」，对着麦克风说中文；
2. 停顿约 0.75 s 内断句，2 s 内（base 基线）出现英文译文并自动开始播报；
3. 切换 美式↔英式 后，下一句播报音色随之改变（Aria ↔ Sonia），LLM 模式下译文拼写/用词风格随之调整；
4. 默认口音为美式（首次启动即为美式）；
5. 未配置 API Key 时全流程可用（Whisper 直译），状态栏提示当前引擎；
6. 外放 + 回声防护开启时，播报期间不产生新的识别（不"自翻自"）；戴耳机关闭防护后可边播边录；
7. 历史卡片可重播、可复制、可导出为 txt；
8. 拔掉麦克风 / 网络中断 / 模型缺失均有明确错误提示，不崩溃。

## 7. 术语表

| 术语 | 含义 |
|---|---|
| VAD | Voice Activity Detection，语音活动检测，用于判断"开始说话/说完一句话" |
| ggml 模型 | whisper.cpp 使用的量化模型文件（如 ggml-base.bin） |
| Whisper 直译 | whisper 的 translate 任务：识别中文的同时直接输出英文，无需独立翻译引擎 |
| Edge-TTS | 微软 Edge 浏览器在线神经语音合成服务，提供 en-US/en-GB 音色 |
| 回声防护 | 播报译文期间暂停麦克风拾音，防止扬声器声音被再次识别 |
